# METER SAFETY — Version 1

A front-end prototype for a South African ride-safety community platform.

## Current features
- Home page
- Ride search prototype
- Safety report form prototype
- South African province page
- About page
- Contact page
- Responsive mobile layout
- JavaScript form/search interactions

## Important
This version does not have a database. Reports are not stored.

The future platform should include secure storage, moderation, privacy controls,
report-review workflows and appropriate legal/contractual checks before publishing
information about identifiable drivers or vehicles.

## Open locally
Open `index.html` in a web browser, or use VS Code with Live Server.
